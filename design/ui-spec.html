01全局框架

所有页面共用同一副骨架：左侧 60px 图标栏、顶部 44px 上下文条、中间内容区。内容区最大宽度 1440px，两侧留 32px。窗口窄于 1100px 时左栏收成纯图标，窄于 900px 时给一句「建议放大窗口」，不做手机布局。

  • 页面切换无整屏动画，只做 120ms 淡入。切页不丢滚动位置（同一次会话内记住）。

02交互总则

八条规则，八个页面都遵守。写下来是为了后面每个模块不用重复定义。

  • 没有保存按钮。输入停顿 400ms 或失焦即写入本地库。任何位置刷新，内容都还在。
  • 新增一律行内。每个列表最后一行就是输入框，回车提交并保持焦点，可连续录入；Esc 退出。
  • 编辑靠点击。点文字直接变输入框，Enter 存、Esc 撤回原值。
  • 删除分级。单行条目 hover 出 ×，点了即删，底部弹 5 秒「已删除 · 撤销」；项目、文稿、整份训练记录这类大对象要二次确认。
  • 次要操作藏起来。列表项静止时只显示内容，hover 才浮出删除、移动、复制。
  • 空状态说人话。一句话加一个按钮，不用插画、不用大段引导文案。
  • 模态框只在两处出现：导入数据、清空模块。其余全部用抽屉或行内表单。
  • 跨天处理。打开页面发现上次会话是昨天，首页顶部出一条窄提示「昨天还有 2 条没做完 →」，点进今日计划查看，不自动搬。

  • 四个标签页各自的最小结构：任务按功能/修复/优化分三组、可勾选；Bug是表（严重度、标题、状态、复现步骤）；版本是竖向里程碑，每个版本挂它包含的任务；日志一天一条，按日期倒序。

  • 点 Bug 行展开复现步骤与修复思路，展开状态记在本地，下次进来自动展开上次没关的那条。
  • 日志只有一行输入，回车即存；同一天再写就是追加一段，不覆盖。
  • 切项目时标签页保持不变（在 api-service 看 Bug，切到个人站点还是看 Bug）。

12键盘与状态

全局键位

1–8切到对应模块
⌘K / Ctrl K全局搜索（跨模块找条目）
N当前页新建
Esc关抽屉 / 退出编辑 / 取消输入
⌘Z撤销最近一次删除

在输入框内时数字键与 N 不触发跳转。

保存状态

  • 顶栏右侧一个 6px 圆点。写入中灰色轻微脉冲，完成转绿，1 秒后淡出到半透明。
  • 写失败变红，点开显示原因，通常只有存储空间满。
  • 页面关闭前若有未落盘的输入，用 beforeunload 拦截一次。

跨模块数据关系

  • 今日计划只存引用：{模块, 条目id}，标题变了首页跟着变，不做副本。
  • 首页六张卡各自读一个 summary 查询，不吃全表。
  • 体重只属于饮食模块，运动模块不读它，避免两处改同一件事。
  • 所有模块共用一套 updatedAt，导出时按模块分桶，导入按同样的桶写回。
