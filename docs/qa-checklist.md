# 验收清单 · v1

对应 `PRD.md` 第 10 节 AC-01～AC-38。每条标明是自动用例还是必须手动看。

跑自动用例：

```
cd D:\飞书\APP
npm test
```

浏览器手测前先双击 `start.cmd`。窗口会停在那不关，里面只有三行英文提示；服务起来后浏览器自动打开 `http://127.0.0.1:8787/`。窗口标题栏写着地址，浏览器没自动弹就把地址粘过去。用完直接关这个窗口，服务就停了，数据在浏览器里不受影响。

`start.cmd` 必须保持 CRLF 换行与纯 ASCII。改动后如果双击只看到一屏滚动的命令文本、页面没出来，先查这两点。

## 10.1 安装与启动

- [ ] **AC-01 打开就能用**
  - 步骤：双击 `start.cmd`，等浏览器打开
  - 预期：首页出现日期条、今日完成、今日计划、快速备忘、六张摘要卡；控制台无红色报错
  - 自动化：部分覆盖（`p0` 结构用例、`p6` 九页渲染）

- [ ] **AC-02 断网也照常**
  - 步骤：断开网络，重复 AC-01
  - 预期：行为完全一致，没有任何请求失败提示
  - 自动化：代码层保证（无 fetch、无外链），需手测确认

- [ ] **AC-03 首屏够快**
  - 步骤：数据量 ≤ 500 条时打开首页，看 DevTools Performance 的 FCP
  - 预期：可交互 ≤ 1.5s
  - 自动化：不支持，手测

## 10.2 数据持久化

- [ ] **AC-04 新增后刷新还在**
  - 步骤：今日计划 → 底部输入「测试」回车 → 等 1 秒 → F5
  - 预期：列表第一行仍是「测试」，未勾选
  - 自动化：`p2`「今日计划页能加任务、勾选、删除」

- [ ] **AC-05 关掉浏览器再开还在**
  - 步骤：记几条数据 → 关闭整个浏览器 → 重新打开 `http://127.0.0.1:8787/`
  - 预期：九个模块数据完整
  - 自动化：不支持（跨进程），手测

- [ ] **AC-06 打完字立刻关也不丢**
  - 步骤：在任意输入框打字后 1 秒内关闭标签页
  - 预期：重开后内容在；若被 `beforeunload` 拦下会弹出确认
  - 自动化：`p1` 覆盖写入链路，`beforeunload` 需手测

- [ ] **AC-07 保存状态点**
  - 步骤：改一个任务标题，盯顶栏右侧小圆点
  - 预期：输入时变灰并轻微脉冲，写库成功后转绿，1 秒后淡出
  - 自动化：不支持，手测

## 10.3 备份与恢复

- [ ] **AC-10 坏文件整份拒绝**
  - 步骤：把 JSON 里的 `schema` 改成 999，导入

- [ ] **AC-11 替换前自动备份**

## 已知与 PRD 的偏差

| 项 | 现状 | 说明 |
|---|---|---|
| 命令面板快捷键 | 用 `⌘K` / `Ctrl K` 打开搜索 | 与 PRD 一致 |
| `N` 新建 | 聚焦当前页第一个行内输入框 | 少数页面（运动新建训练、学习新建日程）走按钮 + 抽屉，`N` 会聚焦到页面第一个输入框 |
| 输出物编辑 | 占满内容区，Esc 或「← 返回」退出 | 与 PRD 一致 |
| 版本里程碑挂任务 | 只显示已挂任务数，暂无勾选界面 | 第一版留白，未连到 AC |
